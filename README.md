# PLP Python Week 8 - Personal Multi-Toolkit

## Project Description
This project is a Python-based command-line interactive toolkit. It brings together multiple useful applications—a Simple Calculator, a To-Do List Manager, and a Number Guessing Game—under a unified menu system.

## How to Run
1. Make sure Python 3 is installed on your computer.
2. Open a terminal or command prompt in the project folder.
3. Run the application using the command:
   ```bash
   python toolkit.py
